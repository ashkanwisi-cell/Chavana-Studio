CHAVANA STUDIO — STATIC WEBSITE

OFFLINE USE
Double-click index.html. No installation or setup is needed.

GITHUB PAGES
Upload the contents of this folder to a GitHub repository, then enable GitHub Pages for that repository. Keep the folder structure unchanged.

EDITING CONTENT
- Portfolio titles, descriptions and tags: js/app.js, in the "projects" data near the top.
- Contact and social information: js/app.js, in the English and Persian translation text.
- Other English and Persian text: js/app.js, in the "copy" translation data.

The site uses only local HTML, CSS, JavaScript, logo, poster and video files. It has no build step and no external runtime dependencies.
